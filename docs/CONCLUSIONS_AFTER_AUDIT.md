### Проблема #1: ДУБЛЮВАННЯ БОНУСІВ

**Локація:** `Invoice::calculateUser()` (лінія 394-437)

**Симптоми:**
- Менеджери отримують подвійні/потрійні бонусы
- В таблиці `user_balance` дублюються записи
- Сума бонусів > суми інвойсу

**Причина:**
```php
// ❌ НЕПРАВИЛЬНО: Для кожного item розраховуємо
foreach ($items as $item) {
    getLabelSumFromArtist();  // Викликається N разів!
    // Добавляємо бонус без перевірки на дублікат
}
```

**Рішення:** Побачити PATCH_1_BONUS_DEDUPLICATION.php

**Стан:** ⏳ Потребує виправлення

---

### Проблема #2: RACE CONDITION БЕЗ ТРАНЗАКЦІЇ

**Локація:** `Invoice::calculateUser()` метод

**Симптоми:**
- Нестабільні результати при одночасних розрахунках
- Можлива втрата даних

**Причина:**
```php
// ❌ Нема try/catch з rollback
// Якщо помилка в середині - дані в неконсистентному стані
```

**Рішення:** Додати транзакцію та обробку помилок

**Стан:** ⏳ Потребує виправлення

---

### Проблема #3: INNER JOIN ВИЛУЧАЄ ДОХІД

**Локація:** `ArtistBalanceQueryBuilder::getArtistDirectIncome()` (лінія 73)

**Симптоми:**
- Артисти отримують менше грошей
- Дохід від видалених треків не розраховується

**Причина:**
```sql
-- ❌ ВНУТРІШНІЙ JOIN
INNER JOIN `track` t ON t.id = ii.track_id
-- Якщо трек видалено → дохід втрачено!
```

**Рішення:** Замінити на `LEFT JOIN` та обробити `NULL`

**Стан:** ⏳ Потребує виправлення

---

### Проблема #4: НЕМА РОЗПОДІЛУ ФІТІВ

**Локація:** Система не розраховує розподіл коли артист фіч у треку

**Симптоми:**
- Система не вміє розраховувати доходи для фітів
- Таблиця `track_to_percentage` не використовується
- Фіч-артисти можуть не отримати свою частку

**Причина:**
```
Система розраховує дохід по артистах, але нема логіки розподілу
для фітів (коли у треку кілька артистів)
```

**Рішення:** Реалізувати TrackPercentageService

**Стан:** ⏳ Потребує розробки (висока пріоритет)

---

### Проблема #5: ВИДАВНИЧІ ПРАВА НЕ РОЗРАХОВУЮТЬСЯ

**Локація:** Усі фільтри розрахунків

**Симптоми:**
- Видавничі права розраховуються як авторські
- Видавці не отримують свою частку

**Причина:**
```
Таблиця ownership_type існує, але не використовується
Система не розрізняє типи прав (авторські vs видавничі)
```

**Рішення:** Реалізувати OwnershipTypeService

**Стан:** ⏳ Потребує розробки (висока пріоритет)
